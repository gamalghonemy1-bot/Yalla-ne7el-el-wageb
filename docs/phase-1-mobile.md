# Phase 1 – Flutter app (code written; NOT yet built or run)
Setup (platform folders are generated by Flutter, not included):
1. `flutter create --org com.yalla --project-name yalla_mobile /tmp/yalla_mobile`
2. Copy /tmp/yalla_mobile/{android,ios} into mobile/ ; keep our lib/ and pubspec.yaml ; do not copy test/widget_test.dart
3. cd mobile && flutter pub get
4. Android release needs `<uses-permission android:name="android.permission.INTERNET"/>` in android/app/src/main/AndroidManifest.xml
5. Run: `flutter run --dart-define=API_URL=http://10.0.2.2:3000`  (Android emulator → host). iOS simulator: http://localhost:3000.
   Dev over plain http needs android:usesCleartextTraffic="true" (debug only) / iOS ATS exception. Production must be HTTPS.
Screens: login → choose child → homework list (pending/previous) → quiz (touch) → result.
No Flutter automated tests yet.

## Build the APK on GitHub (no local Flutter needed)
1. Push the whole project folder to a GitHub repo (branch `main`).
2. Repo > Settings > Secrets and variables > Actions > Variables > New variable: API_URL = your server address (must be reachable from the phone).
3. Actions tab > "Build Android APK" > Run workflow. When green, download the `yalla-apk` artifact (zip containing app-release.apk).
Workflow file: .github/workflows/build-apk.yml (generates android/ in CI; signed with the debug key = installable, NOT for Play Store).
